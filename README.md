# Алгебраический Калькулятор (C++)

Мой первый учебный проект на C++. 
Консольное приложение для выполнения алгебраических и тригонометрических вычислений.

## Функционал
- **Алгебраические функции:**
  - Вычисление квадратного корня (с проверкой на отрицательные числа).
  - Возведение в степень.
  - Вычисление факториала (с проверкой на отрицательные числа).
- **Тригонометрические функции:**
  - Синус, косинус, тангенс.
  - Котангенс, секанс, косеканс (с защитой от деления на ноль).
- Удобное текстовое меню.

## Стек
- **C++**
- Стандартная библиотека (`<cmath>`, `<iostream>`).

## Как запустить
1. Скопируй код из файла `main.cpp` (или из истории коммитов).
2. Скомпилируй его с помощью g++:
   ```bash
   g++ main.cpp -o calculator
